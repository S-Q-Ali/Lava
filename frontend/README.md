# Lava — Frontend

Vite + React + TypeScript editor shell.

Run:

```
npm install
npm run dev      # development (Vite dev server)
npm run build    # production build → dist/
npm run lint     # oxlint
npx vitest run   # tests
```

This app is the UI layer only; heavy AI and encoding work lives in `backend/` / `tools/ffmpeg/`.

Project docs: see `../docs/` and `../AGENTS.md`.
